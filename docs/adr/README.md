# Architecture Decision Records (ADRs)

This directory contains records of key architectural decisions made in the Byten project.

## What is an ADR?
An Architectural Decision Record (ADR) is a short document that captures a significant architectural choice, along with its context and consequences.

## Format
Each ADR is named with an incremental 4-digit number and title:
`0001-short-description.md`

Every record follows this structure:
- **Title**: Contextual title
- **Status**: [Proposed | Accepted | Superseded | Deprecated]
- **Context**: Why are we making this choice? What constraints exist?
- **Decision**: What did we decide to do?
- **Consequences**: What becomes easier or harder as a result?
